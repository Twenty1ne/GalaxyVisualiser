---Usage (from project root)---

./build/galaxy_viewer.exe <Galaxy history data file>
Data file must have format:
    r theta high_mass_star_mass low_mass_star_mass
With each site seperated by \n and each timestep seperated by an additional \n

---CONTROLS---

Movement
> W - Forward

> S - Backward

> A - Left

> D - Right

> LShift - Down

> Space - Up

Playback
> \< - Step back

> \> - Step forward

> P - Play

Window
ESC - Unfocus
LMouse - Focus
